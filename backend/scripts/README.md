# FreudLaw Utility Scripts

This directory contains utility scripts for data exploration and processing.

## Scripts

### Data Download
- `download_gss_data.py` - Downloads GSS data from Kaggle
- `download_gss_simple.py` - Simple GSS data downloader

### Data Exploration
- `explore_gss_data.py` - Explores GSS dataset structure
- `explore_gss_columns.py` - Analyzes GSS column mappings
- `gss_jury_variables.py` - Identifies jury-relevant GSS variables

### Integration Examples
- `data_integration_analysis.py` - Analyzes data integration
- `gss_integration_example.py` - Example of GSS data integration
- `gss_juror_example.py` - Example of GSS-based juror generation
- `juror_generation_example.py` - Complete juror generation example

## Usage

These scripts are utilities for development and data exploration. They are not part of the main application.

```bash
# Example: Explore GSS data
python scripts/explore_gss_data.py
```

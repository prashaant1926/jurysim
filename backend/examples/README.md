# Examples and Demonstrations

This directory contains example scripts and demonstrations of the jury deliberation system.

## Files

### Dialogue Examples
- `realistic_dialogue_examples.py` - Examples of realistic juror dialogue
- `realistic_dialogue_fix.py` - Dialogue improvement demonstrations
- `varied_dialogue_examples.py` - Variety in juror speech patterns
- `why_dialogue_is_wrong.py` - Analysis of dialogue issues

### Model Explanations
- `reasoning_model_explanation.py` - How the reasoning model works
- `analyze_transcript_quality.py` - Transcript quality analysis tools

## Usage

These are demonstration scripts meant to showcase features:

```bash
# See realistic dialogue examples
python examples/realistic_dialogue_examples.py

# Analyze transcript quality
python examples/analyze_transcript_quality.py
```

# Custom Case Input Examples

## Format 1: Structured Text

When pasting a case description, use this format:

```
Title: State v. Johnson
Summary: Defendant is accused of embezzling $50,000 from their employer over a 2-year period.

Evidence:
- Bank records showing unexplained deposits
- Altered invoices with defendant's login credentials
- Coworker testimony about suspicious behavior
- Defendant's gambling debts
- Missing company checks

Prosecution: The pattern of altered invoices and personal financial gain proves embezzlement.
Defense: The defendant was framed by another employee with access to their credentials.
```

## Format 2: Step-by-Step Input

Choose option 1 for guided input:
1. Case type: fraud
2. Case title: State v. Johnson
3. Summary: (describe the case)
4. Evidence: (enter each piece, press Enter twice to finish)
5. Prosecution argument: (main argument)
6. Defense argument: (main counter-argument)

## Supported Case Types
- murder
- theft
- assault
- fraud
- drug
- other

## Tips for Good Cases

1. **Include 3-8 pieces of evidence** - Too few makes it obvious, too many is overwhelming
2. **Mix evidence types** - Physical evidence, witness testimony, circumstantial evidence
3. **Create ambiguity** - Good cases have evidence that can be interpreted multiple ways
4. **Include both strong and weak evidence** - Real cases aren't perfect
5. **Keep arguments concise** - 1-2 sentences each for prosecution and defense

## Example: Ambiguous Assault Case

```
Title: State v. Chen
Summary: Bar fight where defendant claims self-defense after victim suffered serious injuries.

Evidence:
- Security footage showing argument but fight happens off-camera
- Victim has broken jaw and concussion
- Two witnesses say victim threw first punch
- One witness says defendant was aggressor
- Defendant has no injuries
- Victim's blood alcohol was 0.15
- Defendant called 911 immediately after

Prosecution: Defendant used excessive force causing serious bodily harm beyond self-defense.
Defense: Defendant reasonably defended himself against an intoxicated aggressor.
```
